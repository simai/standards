# AI First and Standard Contract 1.0.0

First combined maintainer-supported stable release, dated 2026-09-14.

## Included contracts

- AI First 1.0.0: small discovery core, optional knowledge/capability profiles,
  selective catalogs, revisions and digests, translations, OpenAPI descriptions,
  bounded transport and separately supplied access credentials.
- Standard Contract 1.0.0: pinned inheritance, contract use, informative references,
  adjacent object declarations, requirement provenance and offline resolution.
- Standard Contract lifecycle 1.0.0: conservative comparison, bounded impact,
  explicit version plans, new-directory preparation, lifecycle status and evidence
  applicability. Normative prose assessment remains a human/owner responsibility.

Python readers, a JavaScript core reader, validators, schemas, examples and
reproducible checks are included. No new required AI First core fields were added
when promoting the candidate. Standard Contract's stable format token is `1.0`;
draft readers do not silently accept it. See [migration](adoption.md).

## Verification and limitations

The [verification record](verification.json) identifies checks for this distribution.
`release-manifest.json` pins supported and historical inputs; `tools/verify_release.py`
rejects missing or modified files. Historical candidate lock bytes are preserved.

This is an author-maintained release for project adoption, not a community or
international certification. Docara and Larena 1.0 product acceptance is still
pending. The first-party JavaScript reader is not an independent external adoption.
No network fetching of Standard Contract references, signatures, automatic project
activation, arbitrary business execution or full OAuth client is included.

The lifecycle preparer excludes business files and always creates a candidate for
review. No automatic draft-2-to-1.0 migration command is provided. Third-party
implementations and production deployments need their own acceptance checks.
