# Production adoption and release readiness

The owner requested a combined supported release on 2026-09-14. The current
release category and acceptance policy are defined in [governance](../../GOVERNANCE.md).
The [stable adoption entry](../../RELEASE-STATUS.md) supersedes previous readiness
notes that treated product pilots as a prerequisite to every stable release.

Docara and Larena 1.0 acceptance is still pending. Larena's partial 0.2 integration
is not a completed 1.0 pilot. Product owners must test their own access boundaries,
publication builds, rollback and requirement checks before production adoption.
The standard release does not perform those deployments.
