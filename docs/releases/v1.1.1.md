# 1.1.1 — reference reconcile fixes

Date: 2026-11-02. Tag: `v1.1.1`. `simai.linkage` and `simai.change-lifecycle`
stay at 1.1.0; only the reference implementation changes.

- A place with an anchor follows only that anchor's dependencies; a place
  without one follows all of them; the anchors of a dependency are never
  followed. A document lists a place per clause it contains, so a new law
  edition marks only the documents that contain a clause resting on that law.
- A norm whose last edition stopped (`effective_to` on or before the reference
  date) is `action-needed` with the date in the instruction.
- An edition in force on the reference date that took effect after the place
  was made is found even when no earlier edition is recorded.

Found while moving the document builder (`mirai-documents`) onto the templates
and norms profiles; its TypeScript reconcile and this reference give the same
status and path for every place of the test documents.

See [1.1.0](v1.1.0.md) for the standards themselves.
