# 1.1.0 — SIMAI linkage and change lifecycle

Date: 2026-11-02. Tag: `v1.1.0`.

## What is new

- [`simai.linkage` 1.1.0](../../standards/simai.linkage/1.1.0/standard.json):
  one way to tell what is current, what is out of date and what to change, for
  every source of units and every consumer. Profiles: framework (exactly the
  1.0.0 rules of `simai/ui-source`), norms (a mirror of official law editions)
  and templates (document templates whose clauses rely on norms).
- [`simai.change-lifecycle` 1.1.0](../../standards/simai.change-lifecycle/1.1.0/standard.json):
  how a public name leaves a source in two dated stages, recorded in an
  append-only journal a tool can upgrade from; a mirror records the dates of the
  original source.
- Core schemas, pinned Framework schemas, the reference implementation
  `standards/linkage.py`, fixtures and `tests/test_standards.py`.

## Compatibility

- AI First 1.0.0, Standard Contract 1.0.0 and its lifecycle profile are
  unchanged; this release adds files only, besides release metadata.
- Framework passports, inventories, change reports and journals validate
  unchanged against the core formats. The Framework keeps its 1.0.0 editions;
  its own `simai.change-lifecycle` 1.0.1 re-pins journal schema 1.2.0.
- The repository moved from `zabarov/ai-first` to `simai/standards`; GitHub
  redirects the old address.
