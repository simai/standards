# Configure authentication

Applies to Example Editor 3.0.

## Requirements

Use a local development project. This is a fictional configuration example.

## Configuration

Replace EXAMPLE_CLIENT_ID with your project client identifier.

```json
{
  "authentication": {
    "enabled": true,
    "clientId": "EXAMPLE_CLIENT_ID"
  }
}
```

## Verification

Confirm that the development sign-in page appears. Do not publish credentials.
