# AI First 1.0 specification

Status: maintainer-supported stable specification `1.0.0`. Wire version: `1.0`.

This directory is the self-contained normative contract for AI First 1.0:

- [Core data model](core.md)
- [Profiles](profiles.md)
- [Discovery and transport](discovery-and-transport.md)
- [Conformance](conformance.md)

`MUST`, `SHOULD`, and `MAY` express requirement strength. Examples and guides
are non-normative. The JSON schemas define structural constraints; prose also
defines semantic and security requirements that schemas cannot express.

AI First describes resources, knowledge, and existing capability contracts. It
does not grant authorization, execute operations, verify publisher truth, or
replace OpenAPI, MCP, A2A, WebMCP, llms.txt, or service discovery protocols.
